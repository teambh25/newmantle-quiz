## 분석

### 1. 전체 invalid 비율

- 일별 invalid 비율은 **10~14% 수준**으로, 추측의 1/10 정도가 사전에 없는 단어임
- 이 중 **82~91%는 한글 invalid**(즉, 한글이지만 vocabulary에 없는 단어)이며, 영문·자모 분리 등 non-hangul은 소수
  - → invalid의 주된 원인은 "오타·입력 실수"가 아니라 **"사전 커버리지 부족"**
- 절대량은 하루 수천~수만 건으로 무시할 수준은 아님

### 2. 세션 단위 영향 — 포기율과의 관계

| date | giveup(with_invalid) | giveup(no_invalid) | 방향성 |
|------|----------------------|--------------------|--------|
| 04-18 | 18.97% | 11.11% | invalid 있는 세션이 **더 많이 포기** (+7.9%p) |
| 04-19 | 0.39% | 1.28% | invalid 있는 세션이 오히려 덜 포기 |
| 04-20 | 18.97% | 26.39% | invalid 있는 세션이 **더 적게 포기** (-7.4%p) |

- 방향성이 날짜마다 **상반되어 일관성이 없음** → 현재 데이터만으로는 "invalid가 포기를 유발한다"고 결론내리기 어려움
- 04-19, 04-20의 역전 현상은 "시도를 많이 하는 적극적인 유저일수록 invalid를 더 많이 만나고, 동시에 포기율도 낮다"는 **교란 변수(시도 횟수)** 가능성이 높음
- 04-18만 invalid가 포기율에 악영향을 주는데, 이날 정답 단어가 특별히 invalid를 유발하는 종류였을 가능성 있음 (정답별 분석 필요)

### 3. 세션별 invalid 비율 분포

- 대다수 세션(04-20 기준 71%)은 invalid 비율이 **0~10% 구간**에 머무름
- 31% 이상으로 invalid가 심한 세션은 **1.6~5.4%**에 불과 → 극단적 피해를 보는 유저는 소수
- 0% 세션 비율이 04-18(19.94%) → 04-20(21.21%)로 큰 변화 없음, 04-19는 55%로 이례적 (세션 수가 적어 통계적 유의성 낮음)

### 4. 단어 분포 — long-tail 구조

- 기간 내 **unique invalid 단어 수 10,318개**, Top 50은 전체 invalid의 **7.9%**, Top 100도 **12%**만 커버
- **상위 단어 추가의 ROI가 낮음** — 예상했던 "몇몇 단어가 대부분 차지" 가설과 반대로, **매우 긴 long tail 구조**
- 즉 Top 100을 전부 추가해도 전체 invalid 비율은 약 10% → 8.8% 수준으로만 감소 (절대 개선 폭 1~2%p)
- 또한 Top 100을 질적으로 살펴보면:
  - **사전 추가가 부적절한 항목이 다수**: 욕설(씨발, 븅신), 고유명사(해리포터, 포켓몬, 유튜브, 뉴맨틀), 신조어/유행어(이세계, 방탈출), 오타성(붕신, 배게, 악세서리)
  - **추가해도 자연스러운 항목**: 명사형 활용(바꿈, 뛰기, 배움, 쉼), 합성어(인공지능, 전자기기, 미세먼지) 등 — 이것도 전체의 일부에 불과
- → Top-N 단어 추가 전략으로는 **invalid 문제를 구조적으로 해결할 수 없음**이 확인됨

### 5. 리텐션 영향 — 치명도 직접 지표

#### 전체 유저 (n=1,894)
- D+1 리텐션이 invalid 비율에 따라 **명확한 단조 감소** 패턴
  - 1-10% (54.5%) → 11-20% (33.2%) → 21-30% (16.7%) → 31-50% (3.1%) → 51%+ (0.0%)
- D+2도 동일 경향: 1-10% (33.9%) → 11-20% (18.4%) → 21-30% (9.5%) → 31-50% (8.3%) → 51%+ (0.0%)
- **0% 버킷(D+1 5.4%)은 예외적으로 낮음** — invalid를 겪지 않았는데도 리텐션이 최하위라는 것은, 이 구간이 "한두 번 시도하고 이탈한 저참여 세션"을 다수 포함한다는 방증 (선택 편향). 즉 0% 버킷은 비교 기준선에서 제외하는 편이 타당

#### 로그인 유저 (n=196)
- 참여도가 높은 코호트임에도 동일하게 강한 음의 상관
  - 1-10% (76.1%) → 11-20% (50.0%) → 21-30% (50.0%) → 31-50% (0.0%)
- **31-50% 구간에서 D+1 리텐션 0%** (n=5) — 표본이 작긴 하나, 고-invalid가 참여 유저조차 완전히 이탈시킬 수 있다는 시그널
- 로그인 유저는 전반적으로 리텐션이 높음에도 감소 기울기는 전체 유저와 유사 → invalid 영향은 참여도와 무관하게 작동

#### 해석
- 포기율 분석은 날짜별 방향성이 뒤집혀 결론이 모호했으나, **리텐션은 invalid 비율과 강하고 일관된 음의 상관**을 보임
- 1-10% → 31-50% 구간 D+1 리텐션 악화: **54.5% → 3.1% (약 17배)** — 단일 세션 내 마찰(포기)을 버텨도 **"다시 돌아오지 않는 형태의 이탈"** 로 누적되는 것으로 보임
- 리텐션은 "서비스 치명도"를 직접 측정하는 지표이므로, 포기율에서 보이지 않던 악영향이 여기서 드러난 점은 **기존 결론의 주요 반증**
- 다만 고-invalid 구간(31-50%: n=46, 51%+: n=13)은 표본이 작아 유의성 검증 필요

### 6. 잠정 결론 — 서비스 치명도

- **기존 "치명적 문제 아님" 판단은 리텐션 데이터로 재검토 필요**
  - 포기율 기준으로는 invalid의 악영향이 일관되지 않았으나, **리텐션 기준으로는 명확한 음의 상관** 관측
  - invalid 11% 이상 세션에서 D+1 리텐션이 급격히 감소 → "돌아오지 않는 이탈" 형태로 누적되는 중
  - 세션별 invalid 비율 분포(§3)에서 11% 이상 세션은 04-20 기준 ~29%로 결코 소수가 아님 → 전체 리텐션 지표에 끼치는 영향을 무시하기 어려움
- **단, 해결 방식은 단어 추가가 아님**
  - Top-N 추가로는 invalid 2%p 개선에 그침 (§4) → 구조적 해결책이 아님
  - long-tail 단어 상당수는 "고유명사/신조어/욕설/오타"로, **"왜 안 되는지 알려주는 UX"** 와 **명사형 활용 규칙 확장**이 더 큰 개선을 낼 가능성
- **다만 아래 사항은 주의**
  - 샘플 기간이 3일뿐 → 2주 이상 데이터 확보 후 재검증 필요 (수집 중)
  - 고-invalid 구간(31%+)은 리텐션 표본이 매우 작음 → 통계적 유의성 판단에 한계, 재검증 전까지 단정 금물
  - 0% 버킷 저참여 세션 혼입 → 비교 기준선 설정 시 1-10% 또는 "1회 이상 시도한 세션"을 기본값으로 고려

### 7. 단어 추가 시 접근 방향

- Top-N 추가 전략은 효과가 제한적(Top 100 추가로도 invalid ~2%p 감소)이므로, **invalid 비율을 크게 낮추는 목적**으로는 우선순위가 낮음
- 대신 아래 두 방향이 더 의미 있을 것으로 보임:
  1. **명사형 활용(바꿈/뛰기/배움 류) 대응** — 규칙성이 있으므로 기계적 생성이 가능. vocabulary 전체에 일괄 적용하면 효율적
  2. **UX 개선** — 사전 미등재 단어에 대한 안내 메시지 개선, 유사어 제안 등으로 "왜 안 되는지" 불만을 줄이는 방향
- 개별 고유명사/신조어 추가는 **정답으로 나올 가능성이 있는 단어 중심으로만** 선별 추가 (무분별한 확장은 임베딩 품질 저하 위험)
